## 🚀 使用方法

### 1. 回填最近7天（推荐）

```bash
cd /Users/qmk/Documents/QC/twitter/Carlwang/backfill_kol_tweets
./start_backfill.sh
```

这是最常用的命令，会回填过去7天的数据。

### 2. 回填指定天数

```bash
# 回填最近3天
./start_backfill.sh --days 3

# 回填最近14天
./start_backfill.sh --days 14
```

### 3. 回填指定日期范围

```bash
# 回填2024年12月20日到27日的数据
./start_backfill.sh --start-date 2024-12-20 --end-date 2024-12-27
```

### 4. 控制API调用量

```bash
# 每个list每天最多10页（减少API调用）
./start_backfill.sh --days 7 --max-pages 10

# 每个list每天最多20页（获取更多数据）
./start_backfill.sh --days 7 --max-pages 20
```

## ⚙️ 参数说明

| 参数 | 说明 | 默认值 | 示例 |
|------|------|--------|------|
| `--days` | 回填天数 | 7 | `--days 14` |

## 💡 使用建议

1. **首次回填**：使用默认配置回填7天
   ```bash
   ./start_backfill.sh
   ```

2. **成本控制**：如果担心API成本，先用小范围测试
   ```bash
   ./start_backfill.sh --days 1 --max-pages 5
   ```

3. **数据完整性**：如需完整数据，适当增加页数
   ```bash
   ./start_backfill.sh --days 7 --max-pages 20
   ```
